# Minimal, Django-free dependency set for running the 8-condition PANDORA
# experiments on Google Colab (or any plain Python env).
#
# This deliberately EXCLUDES Django / celery / redis / gunicorn / whitenoise /
# x-tweet-fetcher. The experiment engine
# (backend/ml_pipeline/experiments/pandora_runner.py) drives the Django-free
# ML service classes directly on in-memory PANDORA data, so none of the web
# stack is imported at runtime.
#
# IMPORTANT (Colab): Colab already ships torch, numpy, pandas, scikit-learn,
# scipy and matplotlib -- and its torch is a CUDA build matched to the runtime
# GPU. The lower-bound pins below mean "at least this version"; they let pip
# KEEP Colab's preinstalled CUDA-matched builds instead of replacing them. Do
# NOT hard-pin torch to an exact version on Colab -- an exact pin can pull a
# CPU-only wheel and silently disable the GPU. In practice, on a fresh Colab
# runtime `pip install -r requirements-colab.txt` only needs to add
# transformers, huggingface_hub and pyarrow.

# --- Deep learning (Colab preinstalled; keep its CUDA build) ---
torch>=2.1
transformers>=4.35,<5

# --- Classical ML / arrays (Colab preinstalled) ---
scikit-learn>=1.3
numpy>=1.26
scipy>=1.11

# --- Data IO (PANDORA parquet + HuggingFace download) ---
pandas>=2.1
pyarrow>=14.0
huggingface_hub>=0.20

# --- Plots (presentation metric bars and five-threshold sweep graphs) ---
matplotlib>=3.7
