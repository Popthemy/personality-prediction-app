ABSTRACT 
Personality assessment plays an important role in understanding individual behavioural 
patterns across domains such as education, employment, and digital wellbeing. Traditional 
personality assessment methods rely mainly on questionnaire-based approaches, which can be 
limited by response bias and the inability to capture naturally occurring behavioural signals. 
This study presents the design and implementation of a web -based Big Five personality 
prediction system that combines psychometric assessment with social media text analysis to 
estimate personality traits from digital behavioural data. 
The system was developed using a Django -based architecture that integrates researcher 
management, BFI -44 questionnaire processing, social media post acquisition , text 
preprocessing, contextual feature extraction, machine learning prediction, and personality 
visualization. The methodology involved collecting BFI -44 responses as ground -truth 
personality labels, retrieving and preprocessing social media posts, apply ing a Q -learning-
based selection mechanism to identify informative posts, generating contextual representations 
using the BERT transformer model, expanding training samples through a simplified 
augmentation approach, and applying Lasso/ElasticNet  regression models to predict the five 
personality dimensions of Openness, Conscientiousness, Extraversion, Agreeableness, and 
Neuroticism. The system stores intermediate processing outputs, including embeddings, 
synthetic samples, regression parameters, a nd prediction profiles, enabling traceability and 
interpretation of model results. 
The implemented application successfully demonstrates an end -to-end personality prediction 
workflow, transforming raw social media text and questionnaire responses into explainable Big 
Five personality profiles. Experimental evaluation using stored volunteer records showed that 
the regression models were capable of learning  personality-related patterns from contextual 
text representations, with performance differences observed across personality traits due to 
dataset size and variation in available social media content. The system provides a practical

foundation for explainable personality prediction research by integrating natural language 
processing, machine learning, and web-based data management into a unified platform.

CHAPTER ONE 
INTRODUCTION 
1.0 Introduction 
The present research systematically develops and evaluates an integrated machine learning 
pipeline for predicting the Big Five (OCEAN) personality traits from social media-style textual 
and profile data within a Django-based application. 
This methodological framework directly tackles three persistent challenges in computational 
personality assessment: excessive computational cost when processing large volumes of user-
generated content, chronic scarcity of high -quality labeled personality d atasets, and lack of 
interpretability in deep neural architectures. By addressing these challenges simultaneously, 
the pipeline produces outputs that exhibit high predictive stability, reliability, and 
explainability qualities that are essential for respon sible deployment in high -stakes decision-
making contexts such as student support systems, digital wellbeing monitoring, employment 
screening, and algorithmic fairness auditing (Azucar et al., 2018; Pletzer et al., 2025). 
The significance of this work lies in its novelty: it constitutes the first systematic integration of 
reinforcement learning -based active selection, transformer -based contextual embeddings, 
generative data augmentation, and sparse linear regression tailored to social media personality 
inference. This integrated approach not only advances computational psychology but also 
offers practical utility across four equally weighted application domains: education, health and 
wellbeing, employment, and responsible artificial intelligence governance. 
1.1 Background and Motivation to the Study  
The Big Five Personality Model, comprising Openness to Experience, Conscientiousness, 
Extraversion, Agreeableness, and Neuroticism, represents the most empirically robust and 
widely accepted taxonomic framework in modern personality psychology. Extensive research 
has demonstrated that these five dimensions exhibit strong temporal stability across the 
lifespan, cross-cultural generalizability, and substantial predictive validity for a broad range of 

=== PDF PAGE 14 ===
2 
 
consequential life outcomes. These outcomes include academic performance, mental health 
trajectories, leadership emergence, interpersonal relationship quality, job satisfaction, and 
overall psychological adjustment (Goldberg, 1993; McCrae & Costa, 2008; Pl etzer et al., 
2025). 
Traditional methods of assessing the Big Five rely primarily on self-report questionnaires such 
as the NEO Personality Inventory -Revised (NEO -PI-R), the Big Five Inventory (BFI), or 
shorter variants such as the BFI -10 and BFI-2. While these instruments hav e been rigorously 
validated and show good psychometric properties, they suffer from several well -documented 
limitations. Respondents frequently exhibit social desirability bias, deliberately presenting 
themselves in a more favorable light. Retrospective re call inaccuracies further distort self -
reports, particularly when individuals are asked to reflect on long-term behavioral tendencies. 
Moreover, questionnaire -based assessment lacks scalability for real -time, large -scale, or 
continuous monitoring in digita l environments (Pennebaker et al., 2015; Paulhus & Vazire, 
2007). 
The widespread adoption of social media platforms has fundamentally transformed the 
availability of ecologically valid behavioral data. Platforms such as X (formerly Twitter)  
generate massive volumes of naturalistic text, profile descriptions, activity metadata, and 
network interaction patterns. Linguistic choices, sentiment expression, syntactic complexity, 
topical focus, self-presentation style, posting frequency, follower/following ratios, and group 
memberships all contain detectable correlates of personality traits. Meta -analytic syntheses 
have established moderate to strong associations between digital footprints and Big Five 
dimensions, with correlations typically ranging from 0.29 to 0.42 across studies (Azucar et al., 
2018; Tadesse et al., 2018; Farnadi et al., 2016). 
Recent breakthroughs in natural language processing, most notably the development of 
Bidirectional Encoder Representations from Transformers (BERT), have dramatically 
improved the quality of text representations. BERT captures bidirectional context, enabli ng it 
to encode subtle semantic and pragmatic cues that earlier bag -of-words or static embedding 

=== PDF PAGE 15 ===
3 
 
approaches could not detect. Empirical benchmarks show that BERT -based models routinely 
achieve R² values between 0.32 and 0.48 on personality prediction tasks, compared with 0.12–
0.18 for classical methods (Devlin et al., 2019; Christian et al., 2021; Tsa ni & Suhartono, 
2023). 
Despite these methodological advances, three critical barriers continue to prevent widespread 
practical adoption.  
First, exhaustive processing of entire user content histories through computationally expensive 
transformer models is resource -intensive and often impractical for real -time or large -scale 
applications.  
Second, high -quality labeled personality datasets remain scarce, with most academic 
collections containing fewer than 10,000 cases and many controlled studies limited to 100–200 
participants. This scarcity leads to overfitting and poor generalization.  
Third, the dense, non -linear decision boundaries produced by deep neural networks offer 
limited interpretability, which is unacceptable in regulated domains where accountability, 
fairness audits, and legal compliance are mandatory (Pletzer et al., 2025; Si ngh & 
Ramasubramanian, 2023). 
The current study addresses these barriers through a novel orchestration of four complementary 
paradigms. Q-Learning intelligently identifies and selects the most informative social media 
signals including posts, profile bios, headlines, metadata, and network features thereby 
reducing the computational overhead associated with processing large volumes of text. The 
selected content is then processed by Bidirectional Encoder Representations from 
Transformers (BERT), which generates rich contextual embeddings that capture semantic, 
syntactic, and pragmatic relationships beyond the capabilities of traditional text representation 
methods. These embeddings serve as high -quality feature representations for downstream 
personality prediction. Conditional Generative Adversarial Networks (cGANs)  
subsequently augment the embedding space by generating realistic synthetic representations,

mitigating data scarcity and improving model generalization. Finally, Lasso regression learns 
sparse predictive models that identify the most discriminative embedding dimensions and 
associated personality indicators for each Big Five trait, improving interpretability, reducing 
overfitting, and supporting transparent, accountable decision-making.  
This integrated pipeline targets four domains of high societal relevance. In education, trait -
informed models can support adaptive learning pathways, personalized tutoring, and optimal 
group formation based on complementary personality profiles (Poropat, 2 009; Komarraju & 
Karau, 2008). In health and wellbeing, continuous monitoring of digital emotional expression 
and trait-based adherence prediction can facilitate early intervention and personalized mental 
health support (Stephan, 2009; Rostami et al., 2022). In employme nt, accurate trait inference 
enables better role-trait alignment, team composition optimization, and talent assessment while 
minimizing subjective bias (Barrick & Mount, 1991; Pletzer et al., 2025). In responsible AI 
governance, the pipeline contributes to bias detection in profiling algorithms, establishment of 
ethical screening thresholds, and promotion of fair algorithmic decision -making (Singh & 
Ramasubramanian, 2023). 
Meta-analytic evidence underscores domain -specific predictive strength: conscientiousness 
shows the highest correlation with academic achievement (ρ ≈ 0.41), neuroticism is strongly 
associated with psychological distress (ρ ≈ 0.36), extraversion predicts l eadership emergence 
(ρ ≈ 0.38), and agreeableness facilitates collaborative effectiveness (ρ ≈ 0.32) (Poropat, 2009; 
Barrick & Mount, 1991; Rostami et al., 2022; Pletzer et al., 2025). 
Radar charts are widely used to visualize Big Five personality profiles. These charts present 
the five trait scores on radial axes, forming a pentagon shape that allows easy comparison of 
relative strengths and balances across dimensions. 
X (Twitter) profiles provide concise bios, follower/following counts, posting frequency, and 
interaction patterns that serve as valuable metadata and network signals.

1.2 Problem Statement 
Contemporary approaches to text -based personality prediction continue to face three 
interrelated, empirically documented challenges that undermine both theoretical progress and 
practical utility. 
First, computational inefficiency and prediction instability persist as major obstacles. 
Comprehensive application of BERT to heterogeneous and voluminous social media corpora 
produces outputs that are highly sensitive to minor input volume changes, noise,  or sampling 
variations. Cross-validation variance frequently exceeds acceptable thresholds (σ² > 0.08 in 
many reported studies). No existing framework has effectively incorporated reinforcement 
learning principles to intelligently curate high-value text and profile subsets, thereby preserving 
predictive fidelity while dramatically reducing inference latency and resource demands 
(Christian et al., 2021; Park et al., 2020). 
Second, data scarcity and consequent generalization limitations remain unresolved. High -
quality, personality -labeled datasets are chronically undersized, with most academic 
collections falling well below 10,000 cases and many controlled studies limited to 100–200 
participants. This scarcity precipitates embedding-level overfitting and vulnerability to domain 
shift. Although generative adversarial networks have demonstrated strong augmentation 
performance in vision, medical imaging, and tabular data domains,  their systematic empirical 
validation within the high -dimensional manifold of personality -related BERT embeddings is 
conspicuously absent from the literature (Hortal, 2021; Frid-Adar et al., 2018; Antoniou et al., 
2017). 
Third, interpretability deficits severely restrict deployment in regulated applications. 
Predominant deep architectures sacrifice explanatory transparency, which is indispensable for 
stakeholder accountability in high-stakes contexts such as personnel selection, clinical decision 
support, mental health monitoring, and algorithmic governance. Identification of causally 
relevant linguistic, profile, and behavioral predictors is a prerequisite for regulatory 
compliance, fairness auditing, and ethical use. Spar se regression techniques such as Lasso

remain underutilized in this domain despite their proven capacity to deliver interpretable, high-
accuracy models (Pletzer et al., 2025; Tibshirani, 1996; Muthukrishnan & Rohini, 2016). 
1.3 Aim and Objectives 
The primary aim of this study is to systematically develop, implement, and empirically validate 
an integrated computational pipeline that combines Q -Learning-driven active text and signal 
selection, BERT -based contextual semantic representation, GAN -mediated embedding 
augmentation, and Lasso -regularized sparse regression. The pipeline performs reliable, 
interpretable inference of continuous Big Five personality trait scores from constrained social 
media-style textual and profile corpora. The framework demonstrates clear applicability across 
four high -impact domains: education, health and wellbeing, employment, and responsible 
artificial intelligence governance. 
Objectives 
1. To design and optimize a Q -Learning agent that dynamically selects maximally 
informative text segments, profile descriptions, metadata features, and network signals 
according to defined state representations (prediction uncertainty), actions (item 
selection), and rewards (accuracy improvement), with a target of 30–50% reduction in 
BERT computational requirements. 
2. To extract and appropriately aggregate BERT embeddings using CLS -token pooling 
and recency -weighted averaging from the algorithmically curated signals, thereby 
establishing robust 768-dimensional user-level semantic representations. 
3. To train conditional Generative Adversarial Networks capable of synthesizing 
distributionally realistic (embedding, OCEAN -score) pairs, thereby expanding the 
effective training corpus size by a factor of 2 –3 without inducing mode collapse or 
introducing significant distributional artifacts. 
4. To develop trait -specific Lasso regression models incorporating systematic L1 
regularization, achieving targeted coefficient sparsity greater than 85% through careful

alpha hyperparameter optimization while maximizing predictive performance on 
continuous trait scores. 
5. To conduct comprehensive empirical evaluation using a combination of accuracy -
oriented metrics (R², MAE, RMSE), stability indicators (cross-validation variance, test-
retest reliability), ablation studies demonstrating the contribution of each pipeline 
component, and domain-specific validation protocols. 
1.4 Justification Based on Existing Solutions 
Several existing studies have demonstrated the feasibility of predicting personality traits from 
social media using machine learning and deep learning techniques. However, most solutions 
focus on a single modelling approach, such as transformer-based language models or traditional 
feature engineering, limiting their ability to address computational efficiency, data scarcity, 
and model interpretability simultaneously. 
Christian et al. (2021) showed that BERT -based language representations significantly 
improve Big Five personality prediction by capturing contextual semantic information from 
social media text. While the model achieved strong predictive performance, it re lies on 
processing large volumes of text, making inference computationally expensive for practical 
deployment. 
Tsani and Suhartono (2023) further improved prediction accuracy by combining BERT and 
RoBERTa with text augmentation techniques. Although their ensemble enhanced classification 
performance, the approach increased computational complexity and did not provide 
interpretable explanations for predicted personality traits. 
Majima and Markov (2022) demonstrated that combining BERT embeddings with handcrafted 
linguistic features improves personality prediction over using contextual embeddings alone. 
However, the system still processes all available text uniformly and lacks an intelligent 
mechanism for selecting only the most informative content before encoding.

Unlike these existing solutions, the proposed system integrates Q-Learning, BERT, 
Conditional GAN, and Lasso Regression  into a unified prediction pipeline. Q -Learning 
minimizes unnecessary BERT computation by selecting high -value social media signals, 
BERT extracts contextual semantic embeddings, Conditional GAN addresses limited training 
data through embedding augmentatio n, and Lasso Regression provides interpretable feature 
selection and transparent personality prediction. This integrated architecture is designed to 
improve prediction accuracy, computational efficiency, robustness on small datasets, and 
explainability, making it more suitable for real-world personality assessment applications. 
1.5 Scope of the Study  
The scope of this investigation is deliberately focused to ensure feasibility, ethical compliance, 
and scientific rigor. The study is restricted to English -language social media -style text and 
profile content. Each participant contributes 3 –5 posts (each approximately 30 –50 words), 
profile bio/about section text (up to 100 words), headline/tagline, pinned post (if available), 
and basic metadata (followers count, following count, post frequency estimate, join date). 
Network signals include the three most frequently interacted accounts and any relevant group 
memberships. 
Data are ethically procured from 80–150 student volunteers through institutional review board-
approved, consent-based web instrumentation (Google Forms).  
The implementation follows a sequential order of data acquisition, text cleaning, Q -learning 
based post selection, BERT contextual encoding, augmentation, and Lasso or ElasticNet 
regression. In practice, the stored runs rely on persisted database artifacts  and cohort-based 
training summaries rather than a purely abstract cross-validation description. 
All four application domains receive equal analytical emphasis:

formation),

1.6 Limitations of the Study  
The study is subject to several inherent limitations that should be acknowledged. 
First, reliance on self-reported Big Five scores (via BFI-44 or similar) introduces potential self-
presentation bias, even though participants are assured of anonymity. Second, the sample size 
(80–150 participants) remains relatively small despite GAN augmentation, which may limit 
statistical power for detecting su btle effects. Third, the exclusive focus on English -language 
content restricts generalizability to non -English-speaking populations. Fourth, the study 
excludes multimodal signals (profile photos, emojis, images, videos) due to ethical complexity 
and computational constraints. Fifth, evaluation is based on controlled, offline experiments 
rather than live, longitudinal deployments, which may affect ecological validity. Sixth, 
potential biases embedded in pre -trained BERT models or in participant self -selection may 
influence results. Finally, high computational requirements for BERT fine -tuning and GAN 
training may limit immediate reproducibility on standard hardware. 
1.7 Definition of Terms  
1. Agreeableness: The orientation toward compassion, cooperation, trust, altruism, and 
prosocial motivation. High agreeableness is associated with empathy, helpfulness, and 

=== PDF PAGE 22 ===
10 
 
conflict avoidance, whereas low agreeableness is characterized by skepticism, 
competitiveness, and a greater focus on self-interest. 
2. BERT Embeddings: Fixed-length (typically 768 -dimensional) contextualized vector 
representations generated by the Bidirectional Encoder Representations from 
Transformers pre -trained language model. These embeddings encode bidirectional 
semantic and syntactic dependencies w ithin input sequences, providing rich 
representations of meaning based on surrounding context (Devlin et al., 2019). 
3. Big Five Personality Traits (OCEAN Model):  A hierarchical, empirically -derived 
taxonomic framework that represents the fundamental dimensions of human 
personality along continuous spectra. The model demonstrates high test -retest 
reliability (r_tt = 0.80 –0.90) and cross -cultural invariance, as established through 
decades of lexical, questionnaire-based, and behavioral validation research (Goldberg, 
1993; McCrae & Costa, 2008). 
4. Conscientiousness: The capacity for self -discipline, organization, dependability, 
industriousness, and goal -directed persistence. High conscientiousness manifests as 
diligence, effective time management, and strong achievement orientation, while low 
conscientiousness is characterized by impulsivity, disorganization, and a more relaxed 
approach to responsibilities. 
5. Extraversion: The tendency toward positive emotionality, assertiveness, sociability, 
and energy derived from social stimulation. Individuals high in extraversion display 
enthusiasm, dominance in social settings, and active affiliation -seeking behavior, 
whereas those low in extraversion (introverts) exhibit reserve, preference for solitude, 
and introspective tendencies. 
6. GAN Augmentation (Generative Adversarial Networks):  A class of machine 
learning frameworks comprising two mutually antagonistic neural networks a generator 
and a discriminator that are trained simultaneously via minimax optimization. The 
generator learns to produce synthetic data instances that preserve the underlying 
distributional characteristics of real data, specifically targeting augmentatio n of high-

=== PDF PAGE 23 ===
11 
 
dimensional embedding spaces in data-scarce regimes (Goodfellow et al., 2014; Hortal, 
2021). 
7. Lasso Regression:  A linear regression technique augmented with an L1 -norm 
regularization penalty (λ‖β‖₁). The penalty term induces coefficient sparsity through 
soft-thresholding, simultaneously enabling automatic variable selection, overfitting 
mitigation, and enhanced interpretability in high-dimensional predictive modeling tasks 
(Tibshirani, 1996). 
8. Neuroticism (Emotional Instability):  The proneness to experience negative affect, 
including anxiety, depression, vulnerability to stress, and emotional lability. High 
neuroticism predicts heightened stress reactivity and mood dysregulation, whereas low 
neuroticism (emotional stability) is ma rked by calmness, resilience, and emotional 
equilibrium. 
9. Openness to Experience:  The disposition toward intellectual curiosity, aesthetic 
sensitivity, imagination, preference for novelty, and receptivity to unconventional ideas 
and experiences. Individuals high in openness tend to exhibit creativity, divergent 
thinking, and cultural e ngagement, whereas those low in openness prefer convention, 
practicality, and routine. 
10. Q-Learning: A model -free reinforcement learning algorithm that iteratively 
approximates the optimal action -value function Q(s,a) through temporal -difference 
updates based on observed state transitions, actions, and rewards. It facilitates policy 
optimization in partially observable environments without requiring a full model of the 
environment dynamics (Sutton & Barto, 2018).

CHAPTER TWO 
LITERATURE REVIEW 
2.1 Conceptual Review 
2.1.1 The Big Five Personality Model (OCEAN) 
The Big Five Personality Model, commonly referred to as the OCEAN framework, is the most 
widely accepted and empirically validated model for describing human personality. The model 
categorizes personality into five broad dimensions: Openness to Experience, 
Conscientiousness, Extraversion, Agreeableness, and Neuroticism. These dimensions have 
been extensively validated across cultures and age groups, making them the standard 
framework for psychological assessment and computational personality prediction (Goldberg, 
1993; McCrae & Costa, 2008). 
Openness to Experience  describes an individual's curiosity, imagination, creativity, and 
willingness to explore new ideas. Individuals with high openness tend to enjoy abstract 
thinking, artistic expression, and intellectual discussions, whereas those with low openness 
generally prefer routine, familiarity, and conventional approaches. 
Conscientiousness reflects self -discipline, organization, reliability, and persistence in 
achieving goals. Highly conscientious individuals are dependable, structured, and 
achievement-oriented, while lower scores are associated with impulsiveness, poor planning, 
and disorganization. 
Extraversion represents sociability, assertiveness, enthusiasm, and positive emotionality. 
Individuals with high extraversion actively seek social interaction and external stimulation, 
whereas introverted individuals prefer solitude, reflection, and smaller social circles. 
Agreeableness measures compassion, cooperation, trust, empathy, and willingness to maintain 
harmonious relationships. Highly agreeable individuals are supportive and collaborative, while 
lower agreeableness is associated with competitiveness and skepticism. 

=== PDF PAGE 25 ===
13 
 
Neuroticism, sometimes referred to as emotional instability, measures susceptibility to 
anxiety, stress, mood swings, and negative emotions. High neuroticism is associated with 
emotional instability, whereas low neuroticism reflects emotional resilience and psychological 
stability. 
The Big Five dimensions demonstrate strong predictive validity across numerous domains, 
including academic performance, job performance, leadership, interpersonal relationships, and 
mental wellbeing (Poropat, 2009; Barrick & Mount, 1991; Roberts et al., 20 07). Their 
consistency and interpretability make the model particularly suitable for automated personality 
prediction systems.

2.1.2 Digital Personality Footprints on Social Media 
Social media platforms have become valuable sources of behavioural data for computational 
personality analysis because they capture spontaneous and natural self -expression. Unlike 
traditional personality questionnaires, users continuously reveal aspects of  their behaviour,

2.2 Theoretical Framework 
2.2.1 Q-Learning for Active Text and Signal Selection 
Q-Learning is a model-free, off-policy reinforcement learning algorithm that learns an optimal 
action-value function without requiring a complete model of the environment. The core update 
rule is derived from the Bellman optimality equation and is expressed as: 
Q(s, a) ← Q(s, a) + α [r + γ max_{a′} Q(s′, a′) − Q(s, a)] 
Where:  
• (s) represents the current state (e.g., current prediction uncertainty or model 
confidence),  
• (a) denotes the action (e.g., selecting a specific post, bio segment, or metadata 
feature),  
• (r) is the immediate reward (e.g., improvement in prediction accuracy or 
reduction in uncertainty),  


=== PDF PAGE 31 ===
19 
 
• (α) is the learning rate controlling the update magnitude 
• (γ) is the discount factor balancing immediate versus future rewards (Sutton & 
Barto, 2018). 
In natural language processing and text classification tasks, Q-Learning has been successfully 
applied within active learning frameworks to intelligently select the most informative instances 
for labeling or processing. This selection reduces annotation cost and computational overhead 
while preserving or even improving model performance compared to random or passive 
sampling. The algorithm prioritizes samples that are expected to yield the greatest expected 
reward, typically measured through uncertainty reduction, expected model change, or expected 
error reduction (Thompson et al., 1999; Settles, 2012). 
In the present pipeline, Q -Learning forms the initial stage. It operates on multi -source social 
media signals from X posts, profile text (bio, headline, about section), metadata 
(followers/following counts, posting frequency, join date), and network featur es (interacted 
accounts, group memberships). The agent learns to select the subset of signals that maximizes 
downstream prediction accuracy while minimizing BERT processing cost. This capability is 
particularly valuable in employment-related applications where human resources professionals 
require rapid, resource -efficient screening of candidate profiles (McCallum & Nigam, 1998; 
Alhathli et al., 2020).

2.2.2 BERT for Contextual Semantic Embedding Extraction 
Bidirectional Encoder Representations from Transformers (BERT) is a transformer -based 
language model that pre -trains deep bidirectional representations by jointly conditioning on 
both left and right context in every layer. Pre -training objectives include m asked language 
modeling (predicting randomly masked tokens) and next sentence prediction, enabling the 
model to learn rich semantic and syntactic relationships (Devlin et al., 2019). 
The architecture consists of multiple transformer encoder layers with self -attention 
mechanisms that allow each token to attend to all other tokens in the input sequence. The output 
embeddings are highly contextualized: the representation of any given toke n depends on the 
entire surrounding context. For sentence -level tasks, the special [CLS] token embedding is 
commonly extracted as a fixed -length (typically 768 -dimensional in BERT -base) aggregate 
representation (Devlin et al., 2019). 
In personality prediction, BERT embeddings capture subtle linguistic markers —word choice, 
sentiment valence, syntactic complexity, topic coherence, and pragmatic intent—that correlate 


=== PDF PAGE 33 ===
21 
 
strongly with Big Five traits. The bidirectional context modeling is particularly advantageous 
for processing professional self-presentation in expressive content on X (Christian et al., 2021; 
Tsani & Suhartono, 2023; Majima & Markov, 2022). 
Within the pipeline, BERT constitutes the second stage. It generates high -quality contextual 
embeddings from the text segments and profile signals previously selected by the Q -Learning 
agent. These embeddings serve as the primary input for augmentation and final prediction.

2.2.3 Generative Adversarial Networks (GANs) for Embedding Augmentation 
Generative Adversarial Networks (GANs) are deep learning models designed to generate 
synthetic data that closely resembles real data. A GAN consists of two neural networks trained 
simultaneously in a competitive process: a generator (G), which creates synthetic samples, 
and a discriminator (D), which attempts to distinguish between real and generated samples. 
During training, the generator continuously improves its  ability to produce realistic samples, 
while the discriminator becomes better at identifying synthetic ones. This adversarial learning 
process enables the generator to learn the underlying distribution of the training data 
(Goodfellow et al., 2014).

2.3 Empirical Review 
The development of the proposed pipeline is informed by a growing body of empirical research 
that validates the effectiveness of BERT, GANs, Q-Learning, and Lasso regression in various 
natural language processing and personality inference tasks. This secti on provides a detailed 
explanation of works that have significantly shaped the methodology and theoretical focus of 
this study. 
Christian et al. (2021) investigated the use of large language model embeddings for personality 
trait prediction, utilizing Reddit comments from the PANDORA dataset. Their methodology 
involved evaluating LLM embeddings through a performance comparison with  zero-shot 
methods and conducting a psychometric validation by correlating embeddings with LIWC and 
emotion features. The results demonstrated that custom -trained deep learning models using 
LLM embeddings significantly outperformed zero -shot approaches by an average of 45% 
across all Big Five traits. They reported moderate reliability for the embeddings, with an 
average Cronbach’s alpha of 0.63, and found strong associations between specific traits and 
linguistic markers, such as the correlation between ope nness and social markers. This work 
establishes BERT and RoBERTa as robust semantic backbones for personality analysis. 
Tsani and Suhartono (2023) developed an ensemble model combining BERT and RoBERTa  
for personality prediction from Twitter and YouTube datasets. To address the challenge of class 
imbalance, they introduced a data augmentation method based on the T5 model, which used 
back-translation to generate paraphrased sentences. Their voting ensemble achieved an average 
F1 score of 0.730 on the Twitter dataset and 0.741 on the YouTube dataset. A key conclusion 
of their research was that the inclusion of data augmentation led to a measurable increase in 
average performance compared to models without such processing. Their study highlights the 
importance of using multiple transformer models and synthetic data to enhance the robustness 
of personality classifiers in noisy social media environments. 
Majima and Markov (2022) proposed a personality prediction system that combined BERT 
embeddings with statistical features extracted from text, such as uni -gram and bi -gram 

=== PDF PAGE 38 ===
26 
 
histograms, topic distributions, and emoticon usage. Their methodology employed a self -
attention mechanism to merge these heterogeneous information sources, allowing the model to 
dynamically prioritize the most relevant signals for each MBTI axis. Using 10 -fold cross -
validation on the Kaggle MBTI dataset, they demonstrated that the addition of statistical 
features slightly improved the performance of the base BERT system, increasing accuracy from 
83.4% to 84.2%. Their work demonstrates that while BERT is po werful for capturing 
contextual dependencies, task -specific statistical information provides critical user -level 
context that improves overall system performance. 
Hortal (2021) explored the use of GANs for data augmentation in the classification of 
imbalanced and scarce datasets, specifically focusing on EEG bio-signals. Their methodology 
utilized a Wasserstein GAN with a gradient penalty (WGAN-GP) to generate synthetic features 
that mirrored the distribution of real training data. They investigated different augmentation 
factors, combining the original dataset with synthetic sets of equal size to increase the total 
training volume. The results showed that the addition of GAN-generated samples provided a 
considerable enhancement in classification accuracy and helped mitigate overfitting. This 
study provides empirical justification for incorporating GAN -mediated augmentation in the 
current personality prediction pipeline to address the limitations of small datasets. 
Frid-Adar et al. (2018) focused on GAN-based synthetic data augmentation for medical image 
classification, using a limited dataset of CT images of liver lesions. 16 Their methodology 
involved synthesized high-quality lesion regions of interest using GAN architectures and then 
training a CNN with both classic and synthetic augmentation. The findings indicated that 
adding synthetic data increased sensitivity from 78.6% to 85.7% and specificity from 88.4% to 
92.4%. Their research demonstrates that GANs can effectively learn and replicate the essential 
features of a complex, high-dimensional data distribution, supporting the generalization of this 
technique to the augmentation of semantic embeddings in personality research. 
Antoniou et al. (2017) conducted a comprehensive survey and evaluation of various data 
augmentation techniques, including generative adversarial networks, for deep learning tasks.28 

=== PDF PAGE 39 ===
27 
 
Their findings highlighted that GAN-based augmentation is an effective tool for dealing with 
small datasets, introducing greater diversity and complexity into the training samples than 
traditional geometric transformations. They concluded that GANs can capture subtle variations 
within the data, leading to more realistic and varied training samples that mimic real -world 
examples. This work establishes the foundational value of GANs as a regularizing mechanism 
that reduces generalization error in scenarios wh ere obtaining high -quality labeled data is 
costly or time-consuming. 
Thompson et al. (1999) investigated active learning for natural language parsing and 
information extraction, presenting a framework where the learner sequentially chooses the 
most informative unlabeled instances to be labeled. Their methodology focused on minimizing 
human annotation effort while producing as high -quality a classifier as possible. They 
demonstrated that active learning can significantly reduce the number of examples required for 
complex linguistic tasks. This research validates the inclusion of a selection mechanism in the 
proposed pipeline, specifically Q-Learning, to intelligently prioritize high-value text segments 
and metadata for processing, thereby achieving gains in computational efficiency. 
McCallum and Nigam (1998) introduced an algorithm for text classification from labeled and 
unlabeled documents using a combination of Expectation -Maximization (EM) and active 
learning. Their methodology showed that unlabeled data can significantly increase  
classification accuracy, particularly when labeled data is scarce. They proposed extensions to 
the basic EM scheme, such as dynamically weighting  the contribution of unlabeled data, to 
reduce bias and improve convergence. Their findings indicate that the combination of EM and 
active learning requires only slightly more than half as many labeled training examples to 
achieve the same accuracy as passive learning, providing strong support for the reinforcement-
based selection strategy utilized in this research. 
Settles (2012) provided a comprehensive review of active learning techniques, including 
uncertainty sampling and query-by-committee methods. The survey explained various practical 
challenges with active learning in real-world settings and highlighted how it can be combined 

=== PDF PAGE 40 ===
28 
 
with diverse machine learning areas. The findings showed that uncertainty -based strategies 
consistently outperform random sampling by focusing on instances where the model makes 
unreliable predictions. This theoretical and empirical evidence supports the use of Q-Learning 
as the initial stage of the personality prediction pipeline, enabling the system to learn an optimal 
policy for signal prioritization based on prediction uncertainty. 
Tibshirani (1996) introduced the Lasso regression method, which combines linear regression 
with L1 -regularization to perform both variable selection and regularization. 18 The 
methodology assumes that the coefficients of the linear model are sparse, meaning that many 
of them are pushed exactly to zero. Tibshirani demonstrated that Lasso achieves both improved 
prediction accuracy and model interpretability by excluding irrelevant covariates from the 
model. This pioneering work serves as the basis for the final prediction layer of the proposed 
system, where Lasso id entifies the most influential 768 -dimensional BERT features for each 
personality trait, ensuring that the model outputs are explainable and auditable. 
Hastie et al. (2015) expanded upon the principles of statistical learning with sparsity, 
specifically evaluating Lasso and its generalizations in high -dimensional settings. Their 
research compared Lasso with other regularization techniques and confirmed it s superior 
performance in producing sparse, stable models when the number of features significantly 
exceeds the number of observations. They highlighted that Lasso’s ability to perform subset 
selection is fundamental for identifying informative features and simplifying complex models. 
This work validates the choice of Lasso for the final prediction stage, where interpretability is 
essential for the responsible application of personality prediction in sectors such as healthcare 
and employment. 
Poropat (2009) conducted a landmark meta -analysis of the relationship between the Big Five 
personality model and academic performance. The methodology involved synthesized results 
from numerous studies to establish the predictive validity of each personali ty dimension. The 
findings revealed that conscientiousness is the strongest and most consistent predictor of 
academic achievement, with a correlation of approximately 0.41. Openness was also found to

Rostami et al. (2022) investigated the association between Big Five personality traits and

neuroticism exhibiting the strongest negative association. They reported that personality traits 
explain a substantial proportion of the variance in psychological wellbeing and resilience. This

Their methodology involved categorizing job roles and performance criteri a to evaluate trait-

transparency required for ethical deployment. The findings emphasized the need for

2.4 Research Gaps 
The existing body of empirical and theoretical work on computational personality prediction 
has made considerable progress, yet several persistent and critical gaps remain that limit the 
development of accurate, efficient, interpretable, and practically de ployable systems for Big 
Five trait inference from social media data. These gaps are evident across methodological 
integration, data handling, interpretability, selection efficiency, and cross-domain applicability. 
Most published studies adopt a single -model or single -paradigm approach. Researchers 
typically fine-tune BERT or similar transformers on post text alone, or they apply classical 
feature engineering techniques such as LIWC and n-grams. Very few investigations attempt to 
combine reinforcement learning for active selection, deep contextual embeddings, generative 
augmentation, and sparse interpretable regression into a unified, end-to-end pipeline. No prior 
work has systematically integrated Q -Learning-driven s ignal selection, BERT -based 
representation, GAN-mediated augmentation, and Lasso regression specifically for personality 
prediction from heterogeneous social media sources that include posts, profile text, metadata, 
and network signals (Christian et al., 2 021; Tsani & Suhartono, 2023; Majima & Markov, 
2022). 
Data scarcity continues to represent a major constraint. Controlled academic datasets for 
personality inference rarely exceed a few hundred participants, and even larger public 

=== PDF PAGE 45 ===
33 
 
collections frequently fall below 10,000 labeled cases. This small sample size leads to 
overfitting, reduced generalization, and high sensitivity to noise or domain shift. Although 
Generative Adversarial Networks have proven highly effective for augmentati on in computer 
vision, medical imaging, and tabular data tasks, their systematic application to the high -
dimensional manifold of BERT embeddings derived from personality-related social media text 
remains largely unexplored. Most personality prediction rese arch still relies on raw, 
unaugmented data, which limits model robustness in small-N regimes (Hortal, 2021; Frid-Adar 
et al., 2018; Antoniou et al., 2017). 
Interpretability remains severely underdeveloped in deep learning approaches. Transformer -
based models such as BERT deliver strong predictive performance but function as opaque 
black boxes. This lack of transparency creates significant barriers in high -stakes domains 
employment screening, mental health monitoring, educational advising, and algorithmic 
governance where stakeholders require clear, auditable explanations of which linguistic, 
profile, behavioral, or network signals drive each trait prediction. Sparse regression methods 
such as Lasso offer a proven path to interpretability through automatic feature selection and 
coefficient shrinkage, yet they are rarely combined with modern contextual embeddings in the 
personality prediction literature (Pletzer et al., 2025; Singh & Ramasubramanian, 2023; 
Tibshirani, 1996). 
Active selection mechanisms are underutilized in this domain. Reinforcement learning 
strategies, including Q-Learning, have demonstrated substantial reductions in annotation cost 
and computational overhead in general NLP tasks such as parsing, classificati on, and 
information extraction. However, their application to intelligently prioritize high-value signals 
from heterogeneous social media sources particularly when posts, bios, headlines, metadata, 
and network features are jointly available has received mi nimal attention. This represents a 
missed opportunity to achieve significant efficiency gains, especially in employment and 
education contexts where rapid, low-cost inference is essential (Thompson et al., 1999; Settles, 
2012; McCallum & Nigam, 1998).

2.5 Conceptual Framework 
The conceptual framework presents the overall architecture of the proposed personality 
prediction system. It integrates reinforcement learning, transformer -based natural language 
processing, generative data augmentation, and sparse regression into a unifie d pipeline for 
predicting the Big Five (OCEAN) personality traits from multi -source data collected from X 
(formerly Twitter). The framework demonstrates how information flows through successive 
processing stages, with each stage contributing a distinct fun ction toward producing accurate, 
robust, and interpretable personality predictions. 
2.5.1 Stage 1: Active Signal Selection 
The first stage collects multiple forms of user information from X, including posts, profile 
biography, profile metadata (such as follower count, following count, posting frequency, and 
account age), and network interactions. Since not all available information contributes equally 
to personality prediction, a Q -Learning agent is employed to identify and prioritize the most 
informative signals. This intelligent selection process reduces unnecessary processing while 
preserving relevant behavioural information required for subsequent analysis. 
2.5.2 Stage 2: Contextual Feature Extraction 
The selected textual information is passed to Bidirectional Encoder Representations from 
Transformers (BERT) for contextual feature extraction. Unlike traditional text representation 
methods, BERT captures the contextual meaning of words by considering bot h preceding and 
succeeding words within a sentence. This enables the model to generate rich semantic

representations that effectively capture linguistic patterns associated with the Big Five 
personality traits. 
2.5.3 Stage 3: Embedding Augmentation 
The contextual embeddings generated by BERT are then supplied to a Conditional Generative 
Adversarial Network (cGAN) during the model training phase. Rather than generating 
synthetic social media posts, the cGAN  produces realistic embedding representations 
conditioned on the corresponding personality traits. This augmentation process increases the 
diversity of the training data, reduces overfitting, and improves the model's ability to generalize 
when only a limited number of labelled samples are available. 
2.5.4 Stage 4: Personality Prediction 
The final stage applies Lasso Regression to the original and augmented embedding 
representations. Lasso performs personality prediction while simultaneously selecting the most 
relevant features through L1 regularization. This produces interpretable predictions for the five 
personality dimensions Openness, Conscientiousness, Extraversion, Agreeableness, and 
Neuroticism while reducing the influence of redundant or less informative features. 
The integration of Q -Learning, BERT, Conditional GAN, and Lasso Regression forms a 
complete personality prediction framework that combines efficient feature selection, 
contextual language understanding, data augmentation, and interpretable prediction. The 
resulting personality profiles can support decision-making in education, health and wellbeing, 
employment, and responsible artificial intelligence applications.

3.6.1 Q-Learning-Based Post Selection 
The first stage of the personality prediction pipeline identifies the most informative posts 
for personality analysis. Rather than processing every retrieved post, the system applies a 
Q-learning-based selection strategy to prioritize posts that are likely  to contribute more 
useful information to the prediction model. This approach reduces the volume of text 
processed by subsequent stages while preserving representative behavioural and linguistic 
information. 
For each participant, the system retrieves the validated posts stored in the database and 
computes a state representation based on selected post characteristics. These characteristics 
include engagement level, publication recency, text length, the presence  of hashtags, and 
the presence of external links. Using these state features, the Q-learning agent estimates the 
expected value of selecting each post and determines whether it should proceed to the 
embedding stage. 
The selection policy follows an epsilon-greedy strategy in which the agent primarily selects 
posts with the highest estimated utility while occasionally exploring alternative posts 
during training. This balance between exploitation and exploration improves  the diversity 
of the selected dataset and prevents the selection process from becoming biased toward a 
small subset of posts. 
The selected posts are flagged within the database and forwarded to the BERT embedding 
module. Posts that are not selected remain available for future processing but are excluded 
from the current prediction cycle. By reducing the number of posts requiring contextual 
encoding, the selection stage decreases computational cost and improves the efficiency of 
the overall prediction pipeline.

deterministic post selection based  on the existing  Q-table. The implementation preserves the 
reinforcement learning structure while  ensuring reproducible experimental  results. Selected 
posts and their corresponding Q-values are stored within the database for later processing. 
4.4.2 BERT Contextual Embedding Extraction 
Selected posts are transformed into contextual representations using the pretrained bert-base-
uncased language model. The  BERT Encoder service tokenizes  each post, 
generates contextual embeddings,  and extracts the  [CLS] token representation as  a 768 -
dimensional feature vector. 

=== PDF PAGE 74 ===
62 
 
Each embedding is  stored in the  BERT_EMBEDDING table, allowing feature  vectors to 
be reused during augmentation, model training, and subsequent analyses. Before advancing to 
the next processing stage, the pipeline verifies  that all generated  embeddings have 
been successfully persisted in the database. 
4.4.3 GAN-Style Data Augmentation 
To improve the diversity of the training data, the system implements a lightweight GAN-style 
augmentation module. Unlike a  conventional Generative  Adversarial Network (GAN), the 
implemented approach perturbs BERT embedding vectors using Gaussian noise and generates 
template-based synthetic text samples. This strategy increases the number of available training 
instances without  introducing the computational  complexity associated with  adversarial 
training. 
The augmentation process  is coordinated by  the GAN Augmenter service. Synthetic 
embedding vectors and their associated metadata are stored in the SYNTHETIC_DATA table 
together with  the generator version  and confidence score. These records are  subsequently 
incorporated into the regression training process. 
4.4.4 Lasso and ElasticNet Regression 
The final prediction  stage applies sparse  linear regression to  estimate the five  Big Five 
personality traits. Before  training, the embedding  vectors are standardized  and the 
target personality scores are  normalized. Depending on  the available training  data, the 
implementation employs  either LassoCV or ElasticNetCV to determine the  optimal 
regularization parameters. 
Separate regression models  are trained for  Openness, Conscientiousness, Extraversion, 
Agreeableness, and Neuroticism. For  each model, the  learned coefficients, intercepts, 
validation statistics,  and prediction metrics  are stored in  the LASSO_MODEL table. The 
sparse coefficients produced by  the models provide  an interpretable representation  of the 
contribution of the extracted language features.

The prediction results  are stored in  the PSYCHOMETRIC_PROFILE table, allowing

SUMMARY, CONCLUSION AND RECOMMENDATIONS 
5.1 Introduction 
The preceding chapters described the motivation, background, design, and implementation of 
the personality prediction system. This final chapter summarizes the work, states the main 
conclusion drawn from the implementation, and proposes realistic recommend ations for 
improvement. In doing so, the chapter treats the project as an academic software artifact that 
has been built, tested, corrected, and evaluated rather than as a purely theoretical proposal. 
This is important because a final -year project should close the loop between intention and 
delivery. The system in this study now does that. It accepts volunteers, stores and scores BFI -
44 survey data, retrieves social media posts, cleans them, applies a selection mechanism, 
creates BERT embed dings, augments the data, trains regularized regression models, and 
presents the results through a dashboard and a live demo interface. 
5.2 Summary of the Study 
The core objective of the study was to build a personality prediction application that could infer 
the Big Five traits from social media-style text while retaining traceability and interpretability. 
The final implementation meets that objective at a prototype level. It uses a clear pipeline and 
a relational database to hold every major artifact, which means that the system does not just 
compute a prediction; it also records how that prediction was produced. 
The system design places special emphasis on four operational domains. In education, the 
predictions can be turned into learning recommendations . In health and wellbeing, the 
personality profile can help identify a need for more structure or stress management. In 
employment, the outputs can support role fit and team composition discussions. In responsible 
AI, the project demonstrates how a transparent and auditable model can be used in a sensitive 
decision-support setting without claiming more certainty than the data allows. 

=== PDF PAGE 81 ===
69 
 
The implementation also makes a stronger point that is easy to overlook in a report: a useful 
project is not only about model accuracy. It is also about data flow, persistence, validation, and 
reproducibility. By storing the BFI surveys, the cleaned posts,  the embeddings, the synthetic 
samples, the model parameters, and the final profiles, the application provides a complete 
evidence chain for each prediction. 
5.3 Major Contributions of the Project 
The first contribution is architectural. The project combines psychometric survey data and 
social media text inside one Django application. That integration matters because it shows how 
a small research tool can be turned into a usable web system with rese archers, volunteers, 
dashboards, and operational workflows. The modular structure also means that each layer can 
be improved independently in future work. 
The second contribution is methodological. The report now presents a corrected account of the 
machine-learning stack: a practical post selection mechanism, a BERT embedding service, a 
simplified augmentation module, and a sparse regression layer. The value here is not in 
claiming an impossible le vel of sophistication. It is in showing that the project has been 
implemented honestly and that each component has a clear role in the pipeline. 
The third contribution is traceability. The use of dedicated database models for volunteers, 
surveys, posts, embeddings, synthetic data, Lasso models, and psychometric profiles gives the 
system a structure that can be defended in a viva. If a panel member asks where a prediction 
came from, the answer is not a vague statement. The answer is a path through stored records 
and reproducible services. 
The fourth contribution is usability. The inclusion of a public -facing landing page, a live 
prediction demo, and a researcher dashboard turns the project from a script into an application. 
Even where the demo endpoint uses a lightweight heuristic, it still  provides a responsive 
interface that can be shown during demonstration while the deeper research pipeline remains 
available in the backend.

5.4 Conclusion 
The study demonstrates that Big Five personality prediction can be implemented as a practical 
web application using a combination of psychometric scoring, natural language processing, 
augmentation, and sparse regression. The final system is not perfect, and the report should not 
present it as if it were. However, it is a real and functioning academic prototype with enough 
depth to show serious understanding of both the software engineering and the machine-learning 
sides of the problem. 
The most important conclusion from the implementation is that the data matters as much as the 
algorithm. The database snapshot shows that the system can process a meaningful number of 
volunteers and posts, but the predictive results also show substantial v ariance. That variance 
reminds us that personality prediction from social media text is a difficult problem and that 
model quality depends heavily on sample size, data diversity, and the quality of the ground 
truth. 
A second conclusion is that transparency should be preferred over overstatement. The corrected 
report now states that the augmentation module is simplified, that the reinforcement -learning 
component is scaffolded rather than fully self-learning in routine execution, and that the public 
demo is heuristic. These clarifications improve the credibility of the work because they allow 
the document to be defended using the actual codebase rather than an embellished description. 
Finally, the project shows that an academic system can still be useful even when it is not fully 
industrialized. The important thing is that the architecture is coherent, the data path is traceable, 
the results are measurable, and the limitations are understood. On those grounds, the project is 
a valid and respectable final-year software engineering and machine-learning study. 
5.5 Limitations of the Study 
The first limitation is dataset size. The current database contains 13 volunteers, 254 posts, and 
8 completed psychometric profiles. That is enough for a demonstration, but it is not enough for 
a fully stable personality model. Small sample sizes make the performance metrics unstable, 
which is reflected in the spread of correlations and R-squared values across stored profiles. 

=== PDF PAGE 83 ===
71 
 
The second limitation is data heterogeneity. Some volunteers have many more usable posts 
than others, and this difference affects how much linguistic evidence the model can extract. In 
practice, personality inference is better when the text is varied and e xpressive. Sparse or 
repetitive timelines reduce the signal available to the BERT encoder and the regression layer. 
The third limitation is augmentation fidelity. The current augmenter is helpful, but it is not a 
full adversarial network trained through generator-discriminator competition. It creates useful 
synthetic samples, yet it does not fully model the statistical complexity of a genuine GAN. The 
report should therefore treat the augmentation stage as a pragmatic extension rather than as a 
final solution. 
The fourth limitation is reinforcement learning maturity. The Q-learning module is structurally 
implemented, but the runtime snapshot shows that the logging table is not yet being populated 
during routine pipeline runs. This means the model selection logic  still behaves more like a 
controlled selector than a continuously learning agent. That is acceptable for an academic 
prototype, but it should be improved before any stronger claims are made. 
The fifth limitation is external validity. The system was tested on the local dataset and the 
current runtime environment, so its generalization to a much larger, more diverse, or 
multilingual population is unknown. The model is therefore best treated as a  proof of concept 
that needs more data and more validation before it can be relied on outside the study context.

    def choose_action(self, state: str, training: bool = True) -> str: 
        """ 
        Choose action using epsilon-greedy strategy. 
         
        Args: 
            state: State representation 
            training: If True, use epsilon-greedy; if False, use greedy 
         
        Returns: 
            'select' or 'skip' 
        """ 
        if training and np.random.random() < self.epsilon: 

=== PDF PAGE 93 ===

            # Explore: random action 
            return np.random.choice(self.actions) 
        else: 
            # Exploit: best known action 
            if state not in self.q_table: 
                self.q_table[state] = {a: 0.0 for a in self.actions} 
             
            q_values = self.q_table[state] 
            max_q = max(q_values.values()) 
             
            # If tie, pick randomly 
            best_actions = [a for a in self.actions if q_values[a] == max_q] 
            return np.random.choice(best_actions) 
     
    def update_q_value(self, state: str, action: str, reward: float, next_state: str) -> 
Tuple[float, float]: 
        """ 
        Update Q-value using Q-Learning update rule. 
         
        Q(s,a) = Q(s,a) + α[r + γ*max(Q(s',a')) - Q(s,a)] 
         
        Returns: 
            (old_q_value, new_q_value) 

=== PDF PAGE 94 ===
82 
 
        """ 
        if state not in self.q_table: 
            self.q_table[state] = {a: 0.0 for a in self.actions} 
        if next_state not in self.q_table: 
            self.q_table[next_state] = {a: 0.0 for a in self.actions} 
         
        old_q = self.q_table[state][action] 
        max_next_q = max(self.q_table[next_state].values()) 
         
        # Q-Learning update 
        new_q = old_q + self.alpha * (reward + self.gamma * max_next_q - old_q) 
        self.q_table[state][action] = new_q

        return old_q, new_q
